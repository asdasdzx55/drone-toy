## 🚀 كيفية رفع الصفحة وتشغيلها على GitHub Pages مجاناً

### الطريقة الأولى: عبر أوامر Git في سطر الأوامر (Terminal)

1. قم بإنشاء مستودع جديد (Repository) فارغ على حسابك في GitHub (مثلاً باسم `drone-toy`).
2. افتح موجه الأوامر في مجلد المشروع ونفذ:

```bash
git add .
git commit -m "إطلاق لاندينج بيج طائرة التحكم عن بعد"
git branch -M main
git remote add origin https://github.com/اسم_حسابك/drone-toy.git
git push -u origin main
```

3. بعد رفع الملفات، اذهب إلى صفحة المستودع على GitHub:
   * ادخل على **Settings** (الإعدادات).
   * من القائمة الجانبية اضغط على **Pages**.
   * تحت خيار **Build and deployment**:
     * اختر في **Source**: `Deploy from a branch`.
     * اختر في **Branch**: `main` والمجلد `/(root)`.
     * اضغط **Save**.
4. خلال دقيقة واحدة ستظهر لك رسالة خضراء مع رابط موقعك المباشر، مثل:
   `https://username.github.io/drone-toy/`

---

### الطريقة الثانية: الرفع المباشر عبر موقع GitHub (بدون أوامر)

1. أنشئ مستودعاً جديداً (New Repository) على موقع [github.com](https://github.com).
2. اضغط على زر **uploading an existing file**.
3. اسحب جميع ملفات هذا المجلد (`index.html`, `README.md`, ومجلدات `css`, `js`, `assets`) وأفلتها في المتصفح.
4. اضغط على **Commit changes**.
5. ادخل على **Settings** > **Pages** > واختر الفرع `main` ثم اضغط **Save**.
6. مبروك! موقعك الآن يعمل على الإنترنت وجاهز لاستقبال الطلبات على رقم الواتساب الخاص بك: **01125611779**.
